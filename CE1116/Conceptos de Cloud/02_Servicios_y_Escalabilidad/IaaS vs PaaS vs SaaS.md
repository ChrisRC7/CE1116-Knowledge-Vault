## 📚 Idea/Concepto 
Los modelos de servicio en la nube se definen por la división de responsabilidades en el stack tecnológico. IaaS proporciona recursos virtualizados (cómputo, red y almacenamiento) donde el usuario gestiona el Sistema Operativo y la seguridad de las aplicaciones. PaaS eleva la abstracción al gestionar el hardware, el SO, el Middleware y el Runtime, permitiendo al desarrollador enfocarse solo en el código. Un nivel superior es el modelo Serverless o FaaS (Functions as a Service), donde el proveedor escala funciones individuales basadas en eventos, eliminando el pago por tiempo de inactividad. Finalmente, SaaS ofrece una aplicación completa lista para el consumo, delegando todo el stack al proveedor. A mayor nivel de abstracción (PaaS/SaaS), aumenta la agilidad pero también el riesgo de Vendor Lock-in o dependencia del proveedor.

## 📌 Puntos Claves (Opcional)
- IaaS: Recursos virtualizados donde el usuario gestiona el Sistema Operativo y la seguridad.
- PaaS: Abstrae hardware, SO, Middleware y Runtime; el usuario gestiona solo el código.
- Serverless/FaaS: Escala funciones por eventos, eliminando pagos por inactividad.
- SaaS: Aplicación completa gestionada por el proveedor.
- A mayor abstracción, mayor riesgo de Vendor Lock-in (dependencia del proveedor).
