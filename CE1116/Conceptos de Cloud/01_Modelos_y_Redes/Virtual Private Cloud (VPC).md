## 📚 Idea/Concepto 
Una Virtual Private Cloud (VPC) es una red lógica aislada y definida por software (SDN) que se ejecuta sobre la infraestructura de un proveedor de nube pública. Se caracteriza por ofrecer al usuario un control total sobre su entorno de red mediante la configuración de direccionamiento IP, subredes, tablas de ruteo y puertas de enlace. A nivel avanzado, la VPC permite la microsegmentación mediante firewalls a nivel de instancia (Security Groups), la interconexión con otras redes mediante VPC Peering y el acceso privado a servicios (PaaS) sin transitar por la internet pública. Además de la privacidad, la SDN garantiza el aislamiento de rendimiento, asegurando que el tráfico de terceros no afecte el ancho de banda del entorno privado.

## 📌 Puntos Claves (Opcional)
- Es una red lógica aislada y definida por software (SDN) dentro de un proveedor de nube.
- Ofrece control total sobre el direccionamiento IP, subredes y tablas de ruteo.
- Permite microsegmentación (Security Groups) y acceso privado a servicios PaaS.
